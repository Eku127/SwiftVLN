# Phase 1: 基于余弦惊奇度的关键帧采样

> 本文档记录了基于视觉惊奇度的非均匀采样策略的设计、实现与实验验证。

---

## 1. 问题背景

### 1.1 动机

在 VLN (Vision-Language Navigation) 任务中，历史帧的采样策略对模型性能有重要影响：

- **当前做法**: 均匀采样（每 N 帧取 1 帧）
- **问题**: 长直道信息冗余，转弯处信息密集，均匀采样可能错过关键决策点

### 1.2 核心假设

| 假设 | 描述 |
|------|------|
| **H1** | 基于内容变化的采样能比均匀采样保留更多语义信息 |
| **H2** | 视觉变化剧烈的帧（转角、新物体）对应导航决策的关键点 |

---

## 2. 方法设计

### 2.1 惊奇度定义

**核心思想**: 用相邻帧的余弦距离作为"视觉惊奇度"的代理指标

$$\text{Surprise}_t = 1 - \text{CosineSim}(f_t, f_{t-1})$$

其中 $f_t$ 是第 $t$ 帧的特征向量。惊奇度越高，说明视觉变化越大。

### 2.2 特征提取流程

```
图像 (H×W) 
    ↓ Qwen2.5-VL ViT
N 个 spatial tokens (N×2048)，N ≈ 391（取决于分辨率）
    ↓ Global Pooling (Mean/Max)
1 个全局特征向量 (2048 维)
    ↓ L2 归一化
归一化特征，用于计算余弦相似度
```

**注意**: Mean Pooling 会将 N 个局部 tokens 平均，可能抹平局部差异。

### 2.3 采样策略对比

| 策略 | 描述 | 特点 |
|------|------|------|
| **Uniform** | 等间隔采样 | 简单、保证时间覆盖 |
| **Pure Top-K** | 选惊奇度最高的 K 帧 | 可能聚集在局部，时间断层 |
| **Segmented Top-K** | 分段选最高惊奇度帧 | 保证覆盖 + 惊奇度优先 |
| **Gap-Constrained** | 带最小间隔的 Top-K | 防止连续选帧 |
| **Hybrid** | 均匀锚点 + 局部惊奇度调整 | 兼顾覆盖与惊奇度 |

### 2.4 评估指标：特征重构误差 (FRE)

**定义**: 衡量选中帧能多好地"代表"整个序列

$$\text{FRE} = \frac{1}{T} \sum_{t=1}^{T} \min_{k \in \text{Selected}} \| f_t - f_k \|^2$$

- **含义**: 对于每一帧，找选中帧中最相似的，计算距离并求平均
- **判据**: FRE 越低，说明采样越能保留原序列信息

## 3. 测试数据设计

### 3.1 数据来源

测试数据位于 `test_data/habitat/`，包含三类典型场景：

| 类型 | 场景 | 特点 | 验证目的 |
|------|------|------|----------|
| **simple** | 长直走廊 | 低信息密度，视觉变化小 | 基准测试 |
| **turns** | 前进+转弯 | 存在视觉突变点 | **核心测试** |
| **spin** | 原地旋转 | 每帧都变化，持续高惊奇度 | 压力测试 |

### 3.2 数据格式

图像命名: `XXXXXX_A.png`
- `XXXXXX`: 帧序号
- `A`: 下一步动作 (0=停止, 1=前进0.25m, 2=左转15°, 3=右转15°)

## 4. 实验结果

### 4.1 首次实验：Pure Top-K 的失败

| 序列类型 | Uniform FRE | Pure Top-K FRE | 变化 |
|----------|-------------|----------------|------|
| simple | 57.25 | 73.57 | **-31%** |
| turns | 74.86 | 176.57 | **-130%** |
| spin | 83.36 | 128.44 | **-57%** |

**发现**: Pure Top-K 的 FRE 反而更差！

**根因分析 - 时间断层问题**:

以 `turns_4` (46帧) 为例：
- Uniform 选帧: `[0, 6, 12, 19, 25, 32, 38, 45]` — 均匀覆盖全序列
- Pure Top-K: `[0, 2, 4, 5, 7, 8, 12, 13]` — 全部集中在前 14 帧！

惊奇度在序列开头较高，Top-K 把预算全花在那里，完全忽略后半段。

### 4.2 多策略对比 (Mean Pooling)

| 策略 | Simple | Turns | Spin | 总评 |
|------|--------|-------|------|------|
| **uniform** | **57.25** | **74.86** | 83.36 | ✓ 最稳健 |
| segmented_topk | 62.73 | 81.08 | 125.38 | ○ 接近 |
| hybrid | 63.66 | 77.60 | **81.67** | ○ spin 略优 |
| gap_constrained | 67.01 | 103.62 | 121.35 | △ 中等 |
| pure_topk | 73.57 | 176.57 | 128.44 | ✗ 最差 |

### 4.3 Max Pooling 对比

| 指标 | Mean Pooling | Max Pooling | 变化 |
|------|-------------|-------------|------|
| 平均余弦相似度 | 0.9786 | 0.9724 | -0.6% |
| 惊奇度范围 | 2.14% | 2.76% | **+29%** |

Max Pooling 略微提升了特征区分度，但不足以改变实验结论。

## 5. 关键发现

### 5.1 特征区分度不足

```
平均余弦相似度: 0.9786
惊奇度范围: 仅 2.14%
```

**问题**: 相邻帧特征高度相似（>97%），惊奇度信号被噪声淹没。

### 5.2 根因分析

| 可能原因 | 说明 |
|----------|------|
| **ViT 设计目标不同** | Qwen2.5-VL ViT 优化语义理解，非帧间差异 |
| **Global Pooling 抹平细节** | Mean/Max Pooling 弱化局部差异 |
| **转弯变化太小** | 每帧 15° 转弯，视觉变化有限 |

### 5.3 验证结果

| 假设 | 结果 | 说明 |
|------|------|------|
| H1 | **未验证** | 特征区分度不足，惊奇度信号太弱 |
| H2 | **部分验证** | 转弯处确有惊奇度峰值，但幅度不够 |

---

## 6. 结论与建议

### 6.1 实验结论

1. **均匀采样在当前条件下最优** — 简单、稳健、有效
2. **Pure Top-K 应避免使用** — 时间断层问题严重
3. **核心瓶颈在特征表示** — 惊奇度方法本身可行，但需要更有区分度的特征

### 6.2 策略推荐

| 场景 | 推荐策略 | 理由 |
|------|----------|------|
| **通用** | Uniform | 最稳健，零风险 |
| 需要惊奇度 | Segmented Top-K / Hybrid | 保证覆盖 + 惊奇度 |
| 禁止使用 | Pure Top-K | 时间断层风险 |

### 6.3 未来优化方向

1. **更好的特征提取器**
   - DINOv2 / CLIP（更适合细粒度差异）
   - 保留空间结构的特征（不做全局 pooling）

2. **多帧累积惊奇度**
   - 累积窗口内的变化，放大信号

3. **结合 action 信息**
   - 利用 action label 作为监督，直接标记转弯帧

4. **空间感知惊奇度**
   - 对比 tokens 的空间分布变化，而非全局特征

## 附录：算法伪代码

### A1. 惊奇度计算

```
输入: 特征序列 F = [f_1, f_2, ..., f_T]
输出: 惊奇度分数 S = [s_1, s_2, ..., s_T]

s_1 = ∞  // 第一帧必选
for t = 2 to T:
    s_t = 1 - cosine_similarity(f_t, f_{t-1})
return S
```

### A2. Segmented Top-K

```
输入: 惊奇度 S, 帧数 T, 预算 K
输出: 选中帧索引

segment_size = T / K
selected = []
for i = 0 to K-1:
    start = i * segment_size
    end = (i+1) * segment_size
    best = argmax(S[start:end])
    selected.append(start + best)
return sorted(selected)
```

### A3. FRE 计算

```
输入: 所有特征 F, 选中索引 Selected
输出: FRE 值

total_error = 0
for t = 1 to T:
    min_dist = min(||f_t - f_k||² for k in Selected)
    total_error += min_dist
return total_error / T
```
